Instalar Centauro Links en un ordenador nuevo

Una guía paso a paso para tener la herramienta de correos funcionando en un ordenador con Windows. No hace falta saber de informática: solo copiar, pegar y comprobar que ves lo mismo que aquí.

¿Solo quieres usar la herramienta? Entonces no instales nada.

La herramienta ya está funcionando en internet. Para preparar y enviar correos basta con abrir este enlace y entrar con tu correo:

links.centauroads.com/panel

Este manual es para tener una copia propia en otro ordenador, por ejemplo para probar cambios sin tocar la que usa el equipo.

Lo que vas a necesitar

Un ordenador con Windows 10 u 11Con permiso para instalar programas.
Conexión a internetSe descargan unos 150 MB en total.
Tu correo del equipoCon el que vas a entrar a la herramienta.
Unos 30 minutosLa mayor parte es esperar a que terminen las descargas.

Tus datos

Escríbelos aquí y los comandos de los pasos 5 y 7 se rellenan solos, listos para copiar. No se guardan ni se envían a ningún sitio: se quedan en esta página mientras la tengas abierta.

Mínimo 12 caracteres. Mejor una frase fácil de recordar, por ejemplo: MiOficinaEnChacao2026.

Falta tu correo y tu contraseña.

Los pasos

  1. Instalar Python 3.12 · 5 minutos

    Python es el programa que hace funcionar la herramienta. Tiene que ser la versión 3.12: con otras versiones más nuevas la instalación falla.

    Descargar Python 3.12 para Windows

    • Abre el archivo que se descargó (python-3.12.10-amd64.exe).
    • En la primera pantalla, marca la casilla «Add python.exe to PATH», abajo del todo. Es importante.
    • Pulsa «Install Now» y espera. Si Windows pregunta si permites cambios, di que sí.
    • Al terminar, pulsa «Close».
    Debes ver: una pantalla que dice «Setup was successful».
    Si ya tenías otro Python instalado (por ejemplo el 3.14), instala este igualmente. Pueden convivir, y en los pasos siguientes usaremos el 3.12 a propósito.

  2. Instalar Git · 5 minutos

    Git es el programa que descarga la herramienta desde internet y la mantiene al día.

    Ir a la descarga de Git

    • En esa página, pulsa el enlace «Click here to download» y abre el archivo descargado.
    • Ve pulsando «Next» en todas las pantallas sin cambiar nada, y al final «Install».
    • Al terminar, desmarca «View Release Notes» y pulsa «Finish».
    Debes ver: la pantalla final «Completing the Git Setup Wizard».

  3. Abrir PowerShell · 1 minuto

    PowerShell es una ventana donde se escriben órdenes. No hay que escribir nada a mano: vas a copiar los comandos de esta página y pegarlos allí.

    • Pulsa la tecla Windows, escribe PowerShell y pulsa Enter.
    • Se abre una ventana azul o negra con texto. Déjala abierta durante todo el proceso.
    • Para pegar un comando en PowerShell: clic derecho dentro de la ventana, o Ctrl + V. Después pulsa Enter.
    Si ya tenías PowerShell abierto antes de instalar Python y Git, ciérralo y ábrelo de nuevo: si no, no los encuentra.

  4. Descargar la herramienta · 3 minutos

    Copia este bloque, pégalo en PowerShell y pulsa Enter. Crea la carpeta centauroads-links dentro de tu carpeta personal y entra en ella.

    cd $HOME
git clone https://github.com/joao1975-rgb/centauroads-links.git
cd centauroads-links

    Ahora prepara Python para la herramienta. Copia, pega y pulsa Enter. Tarda un par de minutos y verás muchas líneas pasar: es normal.

    py -3.12 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
    Debes ver, al final: una línea que empieza por Successfully installed, y otra vez el cursor esperando.
    Si dice que «py» o «git» no se reconoce: cierra PowerShell, ábrelo de nuevo (paso 3) y repite este paso. Si sigue igual, repite el paso 1 o 2, según cuál falte.

  5. Crear el archivo de configuración · 1 minuto

    La herramienta necesita saber quién puede entrar. Este comando crea un archivo llamado .env con tu correo y con una clave de arranque: una clave interna, solo para el primer acceso, que esta página ha inventado para ti.

    Primero escribe tu correo arriba, en «Tus datos».

    Set-Content -Path .env -Encoding ascii -Value "PANEL_BOOTSTRAP=nombre@centauroads.com","SUPERADMIN_USER=arranque","SUPERADMIN_PASS=…"
    Debes ver: nada. Si el cursor vuelve sin mostrar errores, el archivo está creado.
    No cierres esta página hasta terminar el paso 7: la clave de arranque está aquí y se vuelve a usar allí. Si la cierras, repite este paso para generar otra.

  6. Encender la herramienta · 1 minuto

    Copia, pega y pulsa Enter:

    .venv/Scripts/python -m uvicorn app.main:app --env-file .env --port 8005
    Debes ver una línea que dice Uvicorn running on http://127.0.0.1:8005. Esta ventana tiene que quedarse abierta mientras uses la herramienta: si la cierras, la herramienta se apaga.

    Comprueba que funciona abriendo este enlace:

    Comprobar que está encendida

    Debes ver en el navegador un texto que incluye "status":"ok".
    Si el navegador dice que no puede acceder al sitio: mira la ventana de PowerShell. Si muestra un error rojo, vuelve a pegar el comando. Si dice 10048 o «only one usage of each socket address», la herramienta ya estaba encendida en otra ventana: usa esa.

  7. Poner tu contraseña · 1 minuto, solo la primera vez

    Abre una segunda ventana de PowerShell (repite el paso 3; la primera sigue ocupada con la herramienta encendida). Copia, pega y pulsa Enter:

    Primero escribe tu correo y tu contraseña arriba, en «Tus datos».

    Invoke-RestMethod -Method Post -Uri http://localhost:8005/api/panel/arranque/contrasena -ContentType "application/json" -Body '…'
    Debes ver dos columnas, ok y email, con True y tu correo debajo.
    Si ves otra cosa, busca el mensaje en «Si algo sale mal», al final de esta página.

  8. Entrar · 1 minuto

    Abre este enlace, escribe tu correo y tu contraseña, y pulsa «Entrar».

    Abrir la herramienta

    Debes ver el compositor de correos: arriba los botones de las plantillas (A · Cartelera, B · Catálogo…) y a la derecha la vista previa del correo. La instalación ha terminado.

Cada día

La herramienta se apaga al cerrar la ventana de PowerShell o al apagar el ordenador. Para encenderla otra vez, abre PowerShell (paso 3) y pega:

cd $HOME\centauroads-links
.venv/Scripts/python -m uvicorn app.main:app --env-file .env --port 8005

Después entra en localhost:8005/panel. Para apagarla, pulsa Ctrl + C en esa ventana o ciérrala.

Tener la última versión

Cuando haya cambios nuevos en la herramienta, apágala y pega esto en PowerShell. Después enciéndela como cada día.

cd $HOME\centauroads-links
git pull
.venv/Scripts/python -m pip install -r requirements.txt

Dar acceso a otra persona opcional

Todavía no hay una pantalla para añadir personas. Se hace así:

  • Apaga la herramienta y pega notepad .env en PowerShell. Se abre el archivo de configuración.
  • En la primera línea, añade el correo de la otra persona después del tuyo, separado por una coma: PANEL_BOOTSTRAP=tu@centauroads.com,otra@centauroads.com
  • Guarda con Ctrl + S, cierra el Bloc de notas y enciende la herramienta.
  • Repite el paso 7 con el correo y la contraseña de esa persona.

Si algo sale mal

Busca el mensaje que ves. Si no aparece aquí, haz una captura de la ventana de PowerShell y envíala.

«py» o «git» no se reconoce como nombre de un cmdlet

Windows todavía no encuentra el programa recién instalado. Cierra todas las ventanas de PowerShell y abre una nueva. Si sigue pasando, repite el paso 1 (Python), marcando «Add python.exe to PATH», o el paso 2 (Git).

«No suitable Python runtime found» al escribir py -3.12

Tienes otro Python, pero no el 3.12. Haz el paso 1: pueden convivir.

Muchas líneas rojas en el paso 4, con palabras como «Rust» o «metadata-generation-failed»

Se usó una versión de Python distinta de la 3.12. Borra la preparación a medias y repite la segunda parte del paso 4:

cd $HOME\centauroads-links
Remove-Item -Recurse -Force .venv
py -3.12 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
«Credenciales inválidas» en el paso 7

La clave de arranque del comando no coincide con la del archivo de configuración, normalmente porque la página se recargó entre medias. Repite el paso 5 con esta página, apaga la herramienta (Ctrl + C), enciéndela otra vez (paso 6) y repite el paso 7.

«Ese correo no está en la lista de autorizados» en el paso 7

El correo del paso 7 no es el mismo que el del paso 5. Revisa que en «Tus datos» esté bien escrito, repite el paso 5, enciende de nuevo la herramienta y repite el paso 7.

«La contraseña debe tener al menos 12 caracteres»

Escribe una contraseña más larga en «Tus datos» y repite el paso 7.

Al entrar dice «Esa cuenta no tiene acceso al panel»

El correo o la contraseña no coinciden con los del paso 7. Escríbelos otra vez con cuidado. Si no recuerdas la contraseña, repite el paso 7 con una nueva.

Entro, pero vuelve a pedirme el correo

Abre la herramienta con la dirección exacta http://localhost:8005/panel. Si la abres desde otro ordenador de la oficina (con una dirección tipo 192.168…), hay que añadir la línea COOKIE_INSEGURA=1 al archivo de configuración: pídeselo a quien lleve la parte técnica.
